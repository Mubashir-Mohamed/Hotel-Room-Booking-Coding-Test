Read `CLAUDE.md` and `HANDOFF.md` before doing anything else.

Then:

1. Inspect the current Git status and branch.
2. Inspect the repository structure and existing configuration.
3. Read the files referenced by `HANDOFF.md`.
4. Compare the handoff with the current repository state.
5. Summarize:
   - the current objective;
   - what is already complete;
   - what remains;
   - any inconsistencies or blockers.
6. Identify the next useful action.
7. Propose a concise implementation plan before editing if the task is non-trivial, affects multiple areas, adds dependencies, or requires scaffolding.

Do not edit files until you understand the current state.
Do not discard existing changes.
